# GKE `te-nfs` 128Gi Multishare Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the GKE `te-nfs` path create one network-aware 128Gi Enterprise Multishare StorageClass, with an actionable manual template when GCE Metadata is unavailable.

**Architecture:** `k8sAvailCheck.sh` will read and validate only the primary NIC VPC resource path from GCE Metadata before rendering the Google `te-nfs` manifest. The repository YAML is the customer-facing template with an explicit network placeholder; the script retains a rendered heredoc so it remains standalone while preserving the same fixed fields. Regression tests mock Metadata and assert both automatic and manual-fallback paths.

**Tech Stack:** Bash, curl, kubectl, Kubernetes StorageClass YAML, existing Bash regression harness.

## Global Constraints

- The only GKE network lookup is `instance/network-interfaces/0/network` on `metadata.google.internal` with header `Metadata-Flavor: Google`.
- Never request `instance/?recursive=true`, never log unrelated metadata, and never silently fall back to `default`.
- The only maintained GKE StorageClass name and instance reuse label are `te-nfs`.
- Use `tier: enterprise`, `multishare: "true"`, and `max-volume-size: "128Gi"`; do not create `te-nfs-128`.
- Preserve `Retain`, `Immediate`, expansion, and the four existing mount options.
- Metadata failure is a red `FAIL`: print a complete client manual YAML template and direct the operator to confirm the VPC in Google Cloud Console.

- [ ] **Step 1: Add the network lookup function directly before `ensure_nfs_storageclass()`**

```bash
get_gce_primary_network() {
    local metadata_url='http://metadata.google.internal/computeMetadata/v1'
    local network

    network=$(curl -fsS \
        -H 'Metadata-Flavor: Google' \
        --connect-timeout 2 \
        --max-time 5 \
        "${metadata_url}/instance/network-interfaces/0/network") || return 1

    [[ "$network" =~ ^projects/[^/]+/networks/[^/]+$ ]] || return 1
    printf '%s\n' "$network"
}
```
